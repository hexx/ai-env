# 課題解決プロンプト: ai-env に --attach オプションを追加し、同一ディレクトリで起動したコンテナにアタッチ可能にする

## 1. 役割定義 (Persona)
あなたは高度なソフトウェアエンジニアおよび CLI ツール開発のエキスパートです。以下のコンテキストとゴールを基に、正確かつ効率的な実装を行ってください。

## 2. 背景・前提条件 (Context)
- **現状発生している問題**: `ai-env` コマンドには現在、同一ディレクトリで起動したコンテナに対して簡単にアタッチ（接続）する手段が提供されていない。ユーザーはコンテナ ID や名前を手動で調べて `docker exec` や `docker attach` を実行する必要があり、手間がかかる。
- **再現手順**:
  1. あるディレクトリで `ai-env` を実行してコンテナを起動する
  2. 別のターミナルで同じディレクトリに移動する
  3. そのコンテナにアタッチしようとすると、コンテナ名や ID を手動で特定する必要がある
- **関連ファイル/コード**: `ai-env` コマンドのエントリポイントおよびコンテナ管理ロジック（実装箇所の特定から開始）

## 3. 解決すべきゴール (Goal & Objective)
- [ ] `ai-env --attach` オプションを新規に実装する
- [ ] 実行時、カレントディレクトリに関連付けられたコンテナを自動検出し、そのコンテナにアタッチする
- [ ] 同一ディレクトリで起動されたコンテナが存在しない場合、適切なエラーメッセージを表示する
- [ ] 既存の `ai-env` の動作・テストを壊さないこと
- [ ] ヘルプメッセージ（`--help`）に `--attach` オプションの説明を追加する

## 4. 期待する成果物 (Output Format)
- 修正が完了したコード一式、または修正パッチ
- 修正理由とアプローチの簡潔な解説
- 動作確認またはテストの実行結果
