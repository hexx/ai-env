# 課題解決プロンプト: Dockerfile の Playwright ブラウザ制限によるイメージサイズ削減

## 1. 役割定義 (Persona)
あなたは高度なソフトウェアエンジニアおよび問題解決のエキスパートです。Docker イメージの最適化と Playwright のブラウザ構成に精通しており、機能面への影響を慎重に評価しながらサイズ削減を実装できます。以下のコンテキストとゴールを基に、正確かつ効率的な修正を行ってください。

## 2. 背景・前提条件 (Context)
- **現状発生している問題**:
  - `Dockerfile` 内の `npx playwright install --with-deps` は、デフォルトで **全ブラウザ（chromium / firefox / webkit）** をインストールするため、イメージサイズの最大要因になっている（数百MB規模）。
  - PR #100（commit `2f41ec6`）で apt リスト/キャッシュや root・pi ユーザーのキャッシュ/一時ファイル削除によるサイズ削減は実施済み。しかしブラウザ本体のサイズは未着手。
  - サンドボックス（ai-env）で実際にどのブラウザが必要かが未確認のため、PR #100 ではブラウザ制限を意図的に見送った。
- **再現手順（現状のサイズを確認する手順）**:
  1. `docker build -t ai-env .` でイメージをビルドする。
  2. `docker images ai-env` または `docker history ai-env` で `/ms-playwright` 配下のブラウザサイズを確認する。
  3. `npx playwright install --with-deps` のレイヤーが最大級であることを確認する。
- **関連ファイル/コード**:
  - `Dockerfile` の「2. 開発ツール・ライブラリのセットアップ」セクション内、Playwright ブラウザインストールの RUN ブロック:
    ```dockerfile
    RUN npx playwright install --with-deps \
        && chmod -R 755 /ms-playwright \
        && apt-get clean \
        && rm -rf /var/lib/apt/lists/* /root/.cache /tmp/* /var/tmp/*
    ```

## 3. 解決すべきゴール (Goal & Objective)
- [ ] サンドボックスの利用実態を調査し、必要なブラウザ種別（chromium のみで足りるか、firefox/webkit が必要か）を判断する。
- [ ] chromium のみで足りる場合、`npx playwright install --with-deps chromium` に変更して firefox/webkit のインストールを省略し、数百MB規模のサイズ削減を実現する。
- [ ] headed モード（GUI ブラウザ本体）が不要で headless shell で足りる場合は、`--only-shell` オプションの追加も検討する（さらなる削減）。
- [ ] 既存のクリーンアップ処理（`apt-get clean` / `rm -rf /var/lib/apt/lists/* /root/.cache /tmp/* /var/tmp/*` と `chmod -R 755 /ms-playwright`）は維持すること。
- [ ] 変更後に `docker build` が成功すること、およびサンドボックス内で必要な Playwright テストが従来通り動作することを確認する。
- [ ] ブラウザ制限は機能変更を伴うため、判断根拠（どのブラウザが必要/不要か）を PR 概要に明記すること。

## 4. 期待する成果物 (Output Format)
- 修正が完了した `Dockerfile`（または修正パッチ）。
- どのブラウザを残し/削除したかと、その判断理由の簡潔な解説。
- `docker build` の成功ログ、および変更前後のイメージサイズ比較（`docker images` の出力など）。
- 必要な Playwright テストの動作確認結果。
